# LEGO STONE KAZAKHSTAN — лендинг

Одностраничный сайт-визитка для производителя облицовочного лего-кирпича (Астана).
Двуязычный (KZ / RU), адаптивный, без сборки — чистый HTML/CSS/JS в одном файле.

## Структура
- `ui_kits/landing/index.html` — весь сайт (один самодостаточный файл)
- `render.yaml` — конфиг деплоя на Render (static site)

## Локальный запуск
Открыть `ui_kits/landing/index.html` в браузере (нужен интернет — шрифты, иконки и фото
грузятся из CDN). Или поднять локальный сервер:

```bash
python -m http.server 5050 --directory ui_kits/landing
# http://localhost:5050
```

## Деплой на Render
Static Site, publish directory: `ui_kits/landing` (см. `render.yaml`).
